# Package Importer

Google Drive上に置いた `.unitypackage` を、Unity Editorから直接確認・Importするためのツール

- **一覧取得**: Google Apps ScriptのWebアプリ経由（Cloud Consoleでのアプリキー発行・請求先アカウント設定は不要）
- **ダウンロード**: Google Driveの共有リンクから直接取得（Apps Scriptのレスポンスサイズ上限を受けない=数百MB〜GB級のファイルにも対応可能）

## できること

- **リフレッシュ**: 指定したDriveフォルダ内のパッケージ一覧と更新日時を取得し、ローカルにインポート済みのバージョンと比較
- **一覧表示**: 更新があるパッケージは黄色、最新のものは白で表示。更新日時・サイズも表示
- **個別Import**: パッケージを1つずつダウンロードしてインポート（ダウンロード進捗を%表示）
- **一括Import**: 更新があるパッケージだけをまとめてダウンロード＆インポート
- **サイズ検証**: ダウンロード後にDrive上のファイルサイズと突き合わせ、不一致（＝通信が途中で切れた等）ならエラーとして扱い、壊れたファイルがそのままImportされるのを防ぐ

## 構成

```
プロジェクト/
├── Assets/
│   └── Scripts/
│       └── Editor/
│           └── PackageImporter/
│               ├── AppsScriptClient.cs                  ← Apps Script Web Appとの通信（一覧取得のみ）
│               ├── DriveDirectDownloader.cs             ← 共有リンク経由の直接ダウンロード
│               ├── EditorCoroutineUtility.cs            ← Editor用の簡易非同期実行
│               ├── PackageImporter_Window.cs            ← メインのEditorWindow
│               └── PackageImportCache.cs                ← インポート済みバージョンのキャッシュ
└── (Unityプロジェクト外)
    └── AppsScript/
        └── Code.gs
```



## ツールの使い方

1. Unityメニューの **September > Package Importer** を開く。
2. 「設定」に以下を入力（EditorPrefsに保存され、PC/ユーザー単位の設定になるので再入力不要）
   - **Apps Script Web App URL**
   - **Drive フォルダID**
3. 「Import時にダイアログを表示する」をONにすると、Unity標準のインポート確認ダイアログが毎回表示されます。OFFの場合は無人でそのままインポートされます。
4. 「リフレッシュ（更新確認）」を押すと、フォルダ内のパッケージ一覧を取得します。
5. 更新があるものは黄色でハイライトされています
   - 各行の「Import」ボタンで個別にインポートできます（ダウンロード中は進捗%が表示されます）。
   - 下部の「更新済みパッケージを一括Import」で、更新があるものだけをまとめてインポートできます。
6. インポートが完了すると、そのパッケージの更新日時がローカルキャッシュに記録され、次回リフレッシュ時には白（最新）表示になります。

## ローカルキャッシュについて

インポート履歴は以下のファイルに保存されます。

```
<プロジェクトルート>/Library/GoogleDrivePackageImporterCache.json
```

`Library` フォルダは通常Gitなどのバージョン管理対象外なので、特別な設定は不要です。
