# Google Drive Package Importer（Apps Script版）

Google Drive上に置いた `.unitypackage` を、Unity Editorから直接確認・Importするためのツール
**Google Apps ScriptのWebアプリ**経由でDriveにアクセスする

## できること

- **リフレッシュ**: 指定したDriveフォルダ内のパッケージ一覧と更新日時を取得し、ローカルにインポート済みのバージョンと比較
- **一覧表示**: 更新があるパッケージは黄色、最新のものは白で表示　更新日時・サイズも表示
- **個別Import**: パッケージを1つずつダウンロードしてインポート
- **一括Import**: 更新があるパッケージだけをまとめてダウンロード＆インポート

## 構成

```
プロジェクト/
├── Assets/
│   └── Scripts/
│       └── Editor/
│           └── PackageImporter/
│               ├── AppsScriptClient.cs                  ← Apps Script Web Appとの通信
│               ├── EditorCoroutineUtility.cs            ← Editor用の簡易非同期実行
│               ├── GoogleDrivePackageImporterWindow.cs  ← メインのEditorWindow
│               └── PackageImportCache.cs                ← インポート済みバージョンのキャッシュ
└── (Unityプロジェクト外)
    └── AppsScript/
        └── Code.gs                                      ← Google Apps Scriptにコピーするコード
```

Code.gs はUnityプロジェクト内ではなく、Google Apps Script側のもの


## ツールの使い方

1. Unityメニューの **Tools > Google Drive Package Importer** を開く
2. 「設定」に以下を入力（EditorPrefsに保存され、PC/ユーザー単位の設定になる）
   - **Apps Script Web App URL**: 発行したURL
   - **Drive フォルダID**: フォルダID
3. 「Import時にダイアログを表示する」をONにすると、Unity標準のインポート確認ダイアログ（取り込むアセットを選べる画面）が毎回表示される　OFFの場合は無人でそのままインポートされる
4. 「リフレッシュ（更新確認）」を押すと、フォルダ内のパッケージ一覧を取得する
5. 更新があるものは黄色でハイライトされる
   - 各行の「Import」ボタンで個別にインポートできる
   - 下部の「更新済みパッケージを一括Import」で、更新があるものだけをまとめてインポートできる
6. インポートが完了すると、そのパッケージの更新日時がローカルキャッシュに記録され、次回リフレッシュ時には白（最新）表示になる

## ローカルキャッシュについて

インポート履歴は以下のファイルに保存される

```
<プロジェクトルート>/Library/GoogleDrivePackageImporterCache.json
```

`Library` フォルダは通常Gitなどのバージョン管理対象外
