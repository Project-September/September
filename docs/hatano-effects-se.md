# ハタノの射撃エフェクト・SE

## 後から設定する項目

キャラクターの既存 `HatanoWeaponController` に以下を設定する。Prefabへのアサインは今回行っていない。

| Inspector フィールド | 用途 |
| --- | --- |
| `_muzzleFlashPrefab` | 二丁拳銃の左右の銃口に発生するマズルフラッシュ |
| `_bulletTrailPrefab` | 各銃口から命中地点、または射程端まで移動する軌跡 |
| `_bulletHitPrefab` | 地形・プレイヤー等のコライダーへの着弾 |
| `_bulletTrailSpeed` | 軌跡の移動速度（既定100） |
| `_effectLifetime` | 単発エフェクトの破棄時間／軌跡到着後の残存時間（既定2秒） |

各エフェクトは通常のGameObject Prefabを使用し、未設定の項目はスキップする。ParticleSystemはPlay On Awakeを有効にする。進行方向・着弾面法線をローカル+Zとして回転する。軌跡は到着後にParticleSystemとTrailRendererの発生を停止し、残存時間後に破棄する。キャラクター消滅時も生成物の破棄予約は残る。

着弾演出は既存の即時命中判定と同時に発生する。演出用の移動速度はダメージタイミングに影響しない。発射結果はStateAuthorityから全クライアントへ通知し、各端末でRaycastを再実行しない。右銃口の方向計算も右銃口基準に修正した。

## SE

`ALLCue.acb` に存在する以下のキューを3D再生する。

- 二丁拳銃の発射：`SE_Hatano_Shoot`（左右一組の射撃につき1回）
- 武器切り替え：`SE_Hatano_Aim`（通常時・エイム中とも、切り替え受理時に1回）
- 遠距離インタラクション銃の射撃開始：`SE_Hatano_Shoot`（対象の有無によらず、射撃長押しの初回に1回。入力解除・回避・構え終了後の再射撃で再生）
- 必殺技の構え：`SE_Hatano_Ult_1`（開始から既定0.3秒後。`HatanoUlt._readySoundDelay` で調整、0なら即時。発射・中断・終了で未再生の予約を破棄）
- ロケット生成時：`SE_Hatano_Ult_2`

必殺技の2キューは番号順に構え／発射へ割り当てた。実音の聞き分けは未確認。武器切り替え音は追加依頼により既存の `SE_Hatano_Aim` を使用する。StateAuthorityから全クライアントへ通知してキャラクター位置で3D再生し、初期装備の設定や切り替え不可時には再生しない。レーザー銃は遠距離インタラクト用の連続判定で、今回の弾丸演出の対象は二丁拳銃。
